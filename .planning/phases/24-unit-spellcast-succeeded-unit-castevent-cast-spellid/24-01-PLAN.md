<task type="auto">
  <name>Task 2: Add deduplication to recordCastTable</name>

File: core/spell_trace_core.lua, lines 137-158 (recordCastTable function)

Current implementation pushes `GetTime()` onto the LRUStack unconditionally:
```
function macroTorch.recordCastTable(spell)
    if not spell or not macroTorch.target.isCanAttack then
        return
    end
    ...
    macroTorch.loginContext.castTable[spell][mob].push(GetTime())
end
```
  </read_first>
  <action>
Add short-circuit deduplication at the top of `recordCastTable` (after the nil/isCanAttack guard, before the loginContext guard). The dedup check: if the LRUStack for this spell+mob already exists and its top timestamp is within 0.2 seconds of now, skip the push. This prevents double-recording when both UNIT_CASTEVENT (kept for auto-correction) and UNIT_SPELLCAST_SUCCEEDED fire for the same cast.

Insert after the `if not spell or not macroTorch.target.isCanAttack then return end` guard and the `if not macroTorch.loginContext then return end` guard, and AFTER the castTable[mob] LRUStack initialization (if the stack hasn't been created yet, there's nothing to dedup against):

```
    if not macroTorch.loginContext.castTable[spell][mob] then
        macroTorch.loginContext.castTable[spell][mob] = macroTorch.LRUStack:new(100)
    end
    -- dedup: skip if same spell on same mob within 0.2s
    -- prevents double-recording when both UNIT_CASTEVENT and UNIT_SPELLCAST_SUCCEEDED fire
    local last = macroTorch.loginContext.castTable[spell][mob].top
    if last and (GetTime() - last) < 0.2 then
        return
    end
    macroTorch.loginContext.castTable[spell][mob].push(GetTime())
```

The LRUStack initialization block that was immediately before `push` (the `if not ... then ... = macroTorch.LRUStack:new(100) end` block) moves up to before the dedup check. The `push(GetTime())` stays as-is below the dedup check.
  </action>
