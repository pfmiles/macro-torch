# PLAN: 简化 macroTorch.log 持久化格式

## 目标

将 `macroTorch.log()` 的持久化记录从 `{msg, color}` JSON table 改为纯文本 string。

## 背景

当前 `interface_debug.lua:114` 写入持久化时存储了一个包含 `msg` 和 `color` 两个字段的 table：
```lua
table.insert(messages, { msg = tostring(a), color = color or 'white' })
```

持久化后的格式类似：
```json
{"color": "white", "msg": "[RAW_COMBATLOG] CHAT_MSG_SPELL_AURA_GONE_SELF | Cat Form fades from you."}
```

color 信息对于日志持久化没有必要，重点应该是信息内容本身。

## 任务

### Task 1: 修改持久化写入格式

- **文件**: `interface_debug.lua`
- **行号**: 114
- **操作**: 将 `table.insert(messages, { msg = tostring(a), color = color or 'white' })` 改为 `table.insert(messages, tostring(a))`
- **验证**: 确认 `MACRO_TORCH_LOG` 没有被其他代码读取（已确认：仅 `interface_debug.lua` 内部引用）
