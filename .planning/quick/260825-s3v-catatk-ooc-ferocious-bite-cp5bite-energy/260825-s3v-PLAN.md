<objective>
Fix the unintended OoC (Omen of Clarity) free Ferocious Bite path in catAtk.
Root cause: `cp5Bite` fall-throughs unconditionally to `readyBite` after the
`energyDischargeBeforeBite` attempt, so when the game silently rejects the discharge
cast (Shred behind-verdict flip N1 / GCD boundary N2), an OoC frame bites for free
without spending the proc on a builder.

Purpose: OoC frames must discharge-only. The bite verdict is re-decided on the next
click from a fresh `player.isOoc` sample, so a rejected discharge can never fall
through into an unearned free bite, while all legitimate bite branches keep working.

Approved design (LOCKED, implemented exactly as decided — do not redesign):
1. `cp5Bite`: after the `if shouldDischarge then macroTorch.energyDischargeBeforeBite(clickContext) ... end`
   discharge attempt, add `if clickContext.ooc then return end` (Task 1).
2. `energyDischargeBeforeBite`: entry guard `if clickContext.isDischarged then return end`
   plus `clickContext.isDischarged = true` after the discharge attempt, to dedup the
   same-frame double entry (oocMod then termMod) (Task 2).
3. Do not modify `regularAttack`, `readyBite`, `safeBite`, `tryBiteKillShot`, `oocMod`,
   `termMod` or any other public function (diff-scope gate, Task 3).
4. The two expected direct-bite branches stay untouched: `shouldDischarge=false`
   (`isPseudoInfiniteEnergy`, `ripLeft <= 2.3`) must still reach readyBite/safeBite
   directly (guard placement rule in Task 1).
5. Existing selftest `core/selftest.lua:783-815` "P: cp5Bite triggers bite at 5CP in
   fast battle without Rip or immunity" must keep passing — no selftest edits.
6. Code comments and commit message in English; existing comments stay as-is.

Output: modified `classes/druid/cat.lua` only (two small, additive guard edits inside
cp5Bite + energyDischargeBeforeBite), verified and committed atomically.
</objective>
