# PLAN: tools/cpdamage.lua 新增 "OOC-Bite Criteria" CC 咬决策常量自动计算块（--erps 参数 + --json-out 同步补段）

## 目标

`lua tools/cpdamage.lua <SV> [--erps N] [--json-out <file>]` 的报告在既有 `decisions:` 段之后**新增一段 additive 的 "OOC-Bite Criteria"**：从 aggregate 层既有统计自动算出 CC（清晰预兆）咬决策的两条翻转阈值 R*(A/B) 与 R*(D/B)，并按 `--erps`（能量回速，缺省 10/s）给出 A/B/D 分段判定（A=CC 直接咬、B=免费 builder 后立即咬、D=泄能再咬·现状）；`--json-out` 归档同步新增顶层 `oocBite` 块且保持严格 JSON。11 字段 cpDamage schema、宏本体、Druid.lua 零改动；屏显既有段落字节不变。

理论依据（唯一基准）：`28-OOC-BITE-CRITERIA.md`。B−A = S−35β、D−B = C−37β；翻盘阈值 R*(A/B) = (S−35β)/E、R*(D/B) = (C−37β)/E；分段：ERPS ≥ R*(A/B) → A，R*(D/B) ≤ ERPS < R*(A/B) → B，ERPS < R*(D/B) → D。

## 差异标注（任务描述 vs CRITERIA 文档 → 以文档为准）

- **"E=ERPS×1s" 表述有误**。CRITERIA 文档定义 E = builder 效率 ≈ **最优 claw 档的 dmg/能耗**（读取点 = aggregate 层 claw 行 `avgEff`，"E（claw3 / claw2 口径）17.49 / 15.24 | claw 行 avg dmg/e"）。数值复核：文档派生断点 25.4 = (684.95−35×6.8545)/17.49 = 445.04/17.49 = 25.45 ≈ 25.4——只有 dmg/e 口径能复现；若按任务字面把 E 取成 ERPS×1s 则量纲不符且全部断点数字对不上。"×1s" 实为时间价值折算中 GCD 差 1 秒的数值因子（=1，比值中消去），阈值单位即 ERPS（每秒能量）。**本计划按文档执行：E = claw 行 avgEff（dmg/e），阈值输出单位为 /s**。
- 任务 A/B 锁定 shred 口径单行（R*(A/B)=(S−35β)/E）：文档派生断点表中 "A/B 非背位 free claw" 两行（23.3/21.3）不在任务锁定范围内，本计划不产出（文档 ≥25 实战速记与锁定口径一致）。

## 公式与读取点锁定（执行按此逐字实现，不得自行发明）

新增纯函数 `function oocBiteCriteria(stats, erps)`（放在 `decisionLines` 之后、`printClawShredTable` 注释之前），输入 stats 即 `statsRef` 形状（`{ clawShred, oocTiers, biteRegression }`），返回 `crit` 表（同时供屏显与 JSON 消费）：

| crit 字段 | 定义（锁定） |
|-----------|--------------|
| `crit.erps` | `tonumber(erps) or 10` |
| `crit.usable` / `crit.note` / `crit.b` / `crit.a` | 直通 `stats.biteRegression`：usable 时 `usable=true, b=reg.b, a=reg.a`；否则 `usable=false, note=reg.reason`（reg 缺失时 note='no regression'），此时 E/rAB/rDB/verdicts 全 nil，直接返回 |
| `crit.E` | E(best claw) = max `avgEff` over claw tiers 0..3（条件 `n>0 and avgEff~=nil`）；无 claw 样本则 nil |
| `crit.rAB` | `{ S = S2, E = crit.E, r = (S2 - 35*b)/crit.E }`；S2 = `buckets.shred[2].avgDmg`（仅当 `shred[2].n>0`）；S2 或 E 缺失 → nil |
| `crit.rDB` | `{ bleed2 = { C=C2, E=E2, r=(C2-37*b)/E2 }, bleed3 = { C=C3, E=E3, r=(C3-37*b)/E3 } }`；每层：`claw[t].n>0` 时 C=avgDmg、E=avgEff，否则该层键为 nil；两层全 nil 时整个 rDB 置 nil |
| `crit.verdicts` | rAB 存在时 `{ bleed2 = v2, bleed3 = v3 }`，否则 nil；v_t = rDB[t] 缺失 → nil；`erps >= rAB.r` → 'A'；否则 `erps >= rDB[t].r` → 'B'；否则 'D' |

新增屏显函数 `local function printOocBiteBlock(crit)`（放在 `printBiteLine` 之后、`printReport` 注释之前），行序与文本格式锁定（数字：b/E 用 `fmtEff` %.4f，S/C/a/R* 用 `fmtDmg` %.2f；erps 回显用 `tostring(crit.erps)`；顺序固定 A/B 行 → D/B bleed2 → D/B bleed3 → verdict 行）：

```
OOC-Bite Criteria (28-OOC-BITE-CRITERIA.md; assumed ERPS = 10/s):
  b (bite slope) = 6.8545  a (base) = 1039.16  E (best claw avg dmg/e) = 17.4900
  R*(A/B) = (S - 35b) / E: S (bleed2 shred) = 684.95 -> R* = 25.45/s
  R*(D/B) = (C - 37b) / E: bleed2 claw C = 563.86, E = 15.2400 -> R* = 20.36/s
  R*(D/B) = (C - 37b) / E: bleed3 claw C = 647.11, E = 17.4900 -> R* = 22.50/s
  verdict at ERPS 10/s: bleed2 -> D, bleed3 -> D
```

降级行（锁定文本）：
- 回归不可用：首行照常后仅 `  bite regression unavailable (<note>) - thresholds skipped`
- rAB 缺失：`  R*(A/B) = (S - 35b) / E: no bleed2 shred samples`
- 某层 claw 缺失：`  R*(D/B) = (C - 37b) / E: no bleed<t> claw samples`
- verdict 某层 nil：该层打印 `n/a`（如 `bleed3 -> n/a`）
