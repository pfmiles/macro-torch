# Quick Task 260806-0y9: 修复 druid 猫/熊形态下法力药水误消耗

**Date:** 2026-08-06
**Status:** Ready

## 问题

在猫/熊形态下，`UnitMana("player")` 返回能量/怒气值而非真实法力值，导致 `shouldUseManaPotion()` 阈值判定永远为 true（或完全无意义），法力药水被不断消耗。

SuperWoW 扩展了 `UnitMana` 和 `UnitManaMax`，对德鲁伊返回 `(formPower, casterMana)`，第二个返回值是真实法力值（与形态无关）。当前代码只取了第一个返回值，未利用 SuperWoW 的能力。

## 修改文件

`classes/druid/Druid.lua`

## 任务

### Task 1: 修复 humanFormMana + humanFormManaMax + 阈值 + 降级禁用

**文件:** `classes/druid/Druid.lua`

**改动:**

1. **修改 `humanFormMana`（行 347-349）：** 检测 SuperWoW + cat/bear 形态时，取 `UnitMana` 的第二个返回值（真实法力）
2. **新增 `humanFormManaMax`（humanFormMana 之后）：** 对称逻辑，取 `UnitManaMax` 的第二个返回值（真实法力上限）
3. **修改 `getManaPotionThreshold()`（行 546）：** `UnitManaMax('player')` → `macroTorch.player.humanFormManaMax`
4. **修改 `shouldUseManaPotion()`（行 552-557）：** 无 SuperWoW + cat/bear 形态时直接返回 false，禁用自动法力药水

**验证:** 代码 diff 确认 4 处改动均在 Druid.lua 相邻区域，逻辑符合设计矩阵
