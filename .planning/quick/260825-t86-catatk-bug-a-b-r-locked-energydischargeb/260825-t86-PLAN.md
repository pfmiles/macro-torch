<objective>
Unify the catAtk discharge-bypass fix (scheme R, LOCKED): make
`energyDischargeBeforeBite` return whether a discharge attempt was initiated, and
make `cp5Bite` defer the bite on an attempted discharge — closing the two non-OoC
high-energy bypass holes (A: Shred behind-verdict flip, B: GCD boundary race) left
open by quick 260825-s3v, which guarded the OoC path only.

Purpose: any frame that actually attempts a discharge (OoC or high-energy) must not
fall through into a bite; the bite verdict is re-sampled on the next click. Frames
with no discharge attempt keep the existing fall-through to safeBite, so the 35-74
energy finisher never deadlocks.

Approved design (LOCKED, implemented exactly as decided — do not redesign):
1. `energyDischargeBeforeBite` return contract: isDischarged re-entry guard returns
   true; isPseudoInfiniteEnergy early-exit returns false; the regularAttack branch
   and the Rake fallback both set isDischarged=true and return true; all conditions
   missed returns false.
2. `cp5Bite`'s `if shouldDischarge then ... end` block becomes
   `if macroTorch.energyDischargeBeforeBite(clickContext) then return end`, which
   absorbs and deletes the s3v `if clickContext.ooc then return end` guard and its
   English comment block (replaced by a new comment).
3. The existing `clickContext.ooc -> readyBite / else -> safeBite` selection stays
   unchanged — it serves the shouldDischarge=false branches and the boolean-false
   fall-through.
4. The two shouldDischarge=false skip logics (isPseudoInfiniteEnergy, ripLeft <= 2.3)
   stay as-is — those frames still bite directly.
5. Do not modify regularAttack, readyBite, safeBite, tryBiteKillShot, oocMod,
   termMod, quickKeepRip or dischargeEnergyChangeRelicAndRip (diff-scope gate).
6. Existing P-06 selftest passes untouched; ONE new P test is added right after
   P-06 mirroring its structure; registration, assertion and stub-restore style
   match P-06.
7. Code comments and commit message in English; existing comments (incl. Chinese)
   stay as-is; blank-line style matches the existing functions.
8. Verify with `bash build.sh`; diff confined to classes/druid/cat.lua +
   core/selftest.lua; single atomic commit (SM_Extend.lua is a gitignored artifact).

Output: modified `classes/druid/cat.lua` (return contract + deferral reshape) and
`core/selftest.lua` (one new Category P test), verified and committed atomically.
