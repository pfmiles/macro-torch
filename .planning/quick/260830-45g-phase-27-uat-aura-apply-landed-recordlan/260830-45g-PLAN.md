`core/spell_trace_core.lua` (Phase 27 UAT feedback): the green
`<spell> cast on <mob> landed: <time>` confirmation line currently prints
AFTER `macroTorch.recordLandEvent`, but recordLandEvent dispatches registered
land listeners synchronously — the Ferocious Bite renewal listener

`macroTorch.pairLandIntent` has no print side effects.

the reorder does not change WHICH show calls happen, only their order relative
to recordLandEvent, so no selftest change is needed or planned.

Purpose: restore causal output order for the Phase 27 UAT — the bite-hit
announcement must precede the renewal lines it triggers, in both the self-hit
path (Rake/Ferocious Bite) and the aura-apply path (Rip/Pounce).
